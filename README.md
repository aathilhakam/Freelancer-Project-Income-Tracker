# Freelancer Tracker assignment

The completed application lives in [`freelanceflow/`](freelanceflow/README.md).

```sh
cd freelanceflow
npm install
npm run dev
```

MongoDB and server environment configuration are required before starting. See the [project setup guide](freelanceflow/README.md) for the existing local MongoDB service, authentication setup, tests, and optional sample data.

The original assignment PDF is preserved in this directory. GitHub publication and the public demo video remain user-managed.
